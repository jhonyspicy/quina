# 運営確認用の全テーマ利用例外を店舗単位に限定する

日付: 2026年9月30日

状態: 採用済み・未実装

## 背景

リリース時に、運営側で全テーマの動作を確認したい。通常の店舗専用テーマには、対象店舗の指定とプロ利用期間中という利用条件がある。

## 検討した選択肢

- 運営者アカウントに全テーマ利用の権限を付け、その人が所有・作成する店舗に適用する。
- 運営確認用として明示指定した店舗だけに全テーマの利用例外を付ける。

## 判断と理由

店舗単位の例外を採用する。アカウント単位では、その人が所有・作成するすべての店舗に例外が広がり、動作確認に必要な範囲を超えるため採用しない。

## 影響

指定した運営確認用店舗では、プロ加入の有無や各専用テーマの対象店舗指定を問わず全テーマを利用できる。同じ運営者の他店舗は通常条件のままとする。

具体的な要件、受け入れ条件、未決定事項は[変更仕様](../../openspec/changes/store-exclusive-theme/spec.md)を参照する。例外の付与・解除操作、権限管理、データモデルは本判断では定めない。
