# 個人のアカウントと店舗単位の契約・課金を分ける

日付: 2026年9月30日

状態: 採用済み・未実装

## 背景

店長・オーナーなど個人のアカウントで利用する想定だが、同じ人が複数店舗を管理する場合もある。プロ利用と協力店・パートナー店への特別料金は、対象店舗ごとに扱いたい。

## 検討した選択肢

- 個人のアカウントを契約単位とし、その人が管理する複数店舗をまとめて扱う。
- 個人のアカウントと契約単位を分け、一店舗につき一契約とする。

## 判断と理由

当面は一店舗につき一契約を採用し、プロ契約・課金・クーポンを店舗単位とする。同じ人が管理する店舗でも、一方のみプロ、他方はフリーにでき、特別料金を他店舗へ波及させずに提供できるため。

管理者個人と店舗を分けることは、将来の管理権限の引き継ぎを考える理由にもなる。ただし、引き継ぎの詳細や実装を決定するものではない。

## 影響

個人のアカウントだけを根拠に、その人の他店舗へプロ利用やクーポンの効果を広げない。[店舗単位のテーマ利用例外に関するADR](0001-store-scoped-theme-verification.md)と同じく店舗ごとの条件を保つが、テーマ利用例外を課金やクーポンの例外に拡張する判断ではない。

アカウントと店舗の詳細な関係・操作権限・データモデルは未決定。複数店舗の支払い集約や複数店舗優待も将来の可能性にとどまり、採用していない。

具体的な要件、受け入れ条件、未決定事項は[店舗単位の契約・クーポンの変更仕様](../../openspec/changes/store-subscription-coupons/spec.md)を参照する。
