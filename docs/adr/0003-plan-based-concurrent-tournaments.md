# 店舗のプランに応じて大会の同時実行数を制限する

日付: 2026年10月1日

状態: 採用済み・未実装

## 背景

同店舗で複数大会を同時進行したいという初回対応の要件がある。従来のプロダクト方針は基本機能を共通とし、利用できるテーマだけでプラン差をつける方向だったが、ユーザーから大会の同時実行数もプランで制限したいという追加決定があった。

## 検討した選択肢

- 従来のテーマだけで差をつける方針を維持し、大会の同時実行数にはプラン差を設けない。
- 店舗ごとのプランで大会の同時実行数にも差を設け、フリーは同時1大会、プロは複数大会とする。

## 判断と理由

後者を採用する。複数大会の同時運営をプロの提供価値に含めたいというユーザーの明示的な意図に沿うため。制限の単位は[店舗単位の契約・課金](0002-store-scoped-subscriptions.md)とそろえて店舗とし、管理者個人やリモコン端末の単位にしない。

本判断はプロダクト方針の「テーマだけでプラン差」を変更する。既存ADRの店舗単位契約やテーマ利用例外の判断は維持し、置き換えない。

## 影響

フリー店舗は同時1大会、プロ店舗は複数大会を実行できる。プロの具体的な上限は未決定で、無制限とは決定していない。一大会のリモコン数・表示端末数にプラン差を追加する判断ではない。

待機受付中・撮影画面中の大会を同時実行数に含めるか、プロ利用期間終了時に進行中の複数大会をどう扱うかは未決定。既存の店舗専用テーマの利用条件や、無料の標準テーマでクロックを継続利用できる方針は変更しない。運営確認用の全テーマ利用例外を同時実行数制限の例外へ拡張しない。

具体的な要件、受け入れ条件、未決定事項は[大会単位のリモコン・サイネージ接続と進行操作](../../openspec/changes/tournament-remote-signage/spec.md)を参照する。状態管理元や同期基盤などの技術選定は本判断の対象外。
