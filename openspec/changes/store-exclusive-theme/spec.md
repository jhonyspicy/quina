## 変更の目的と範囲

店舗専用テーマについて、利用できる店舗とプロ利用期間の条件を明確にする。専用の見た目をプロ加入・継続の価値にする。

一店舗に複数の専用テーマを持てる背景には、用途別の利用に加え、専用に制作したテーマが古くなり、新しく作り直すリニューアルの可能性がある。

一般の無料・有料テーマの内訳、課金方式、権限管理やデータモデルはこの仕様で決定しない。

## 確定した要件

### 通常の利用条件

以下は、後述の運営確認用店舗の例外がない店舗に適用する。

- 店舗専用テーマは、そのテーマの利用対象として指定された店舗だけが利用できる。
- 一店舗に複数の店舗専用テーマを紐づけられる。「専用」は利用店舗の限定を意味し、一店舗一テーマの制約ではない。各専用テーマに、指定店舗かつプロ利用期間中という条件を適用する。
- 指定された店舗自身も、プロ利用期間中である必要がある。
- 指定されていない店舗は、プロ利用期間中でもその専用テーマを利用できない。
- 指定店舗のプロ利用期間終了後は、専用テーマを利用できなくなる。ただし、大会進行中に期間が終了した場合の切替タイミングは未決定。
- プロ利用期間が終了しても、無料の標準テーマでクロック自体は継続利用できる。

具体例は、知り合いの店舗「ラウンドツー」専用テーマ。ラウンドツーがプロ利用期間中の場合に利用でき、他の店舗はプロでも利用できない。この例は提供済み・実装済みであることを示さない。

### 運営確認用店舗の例外

- リリース時に全テーマの動作を確認するため、運営確認用として明示指定した店舗だけに全テーマの利用例外を付ける。
- 指定した運営確認用店舗は、プロ加入の有無も各専用テーマの対象店舗指定も問わず、全テーマを利用できる。
- 同じ運営者が所有・作成する他の店舗には例外を広げず、明示指定がなければ通常の利用条件を適用する。
- 例外は店舗単位とし、運営者アカウント単位で所有・作成店舗すべてに全テーマ利用を認める案は採用しない。判断の理由は関連ADRに記録する。

## 受け入れ条件

以下は将来の実装時に確認する条件であり、検証済みではない。

### 通常の利用条件（運営確認用の例外がない店舗）

| 店舗と利用期間 | 期待する利用可否 |
| --- | --- |
| 指定店舗・プロ利用期間中 | 対象の専用テーマを利用できる |
| 一店舗に複数の専用テーマが紐づき、プロ利用期間中 | 紐づく各専用テーマを利用できる。一店舗一テーマに制限しない |
| 他店舗・プロ利用期間中 | 対象の専用テーマを利用できない |
| 他店舗・プロ利用期間外 | 対象の専用テーマを利用できない |
| 指定店舗・プロ利用期間終了後 | 対象の専用テーマを利用できず、無料の標準テーマでクロックを継続利用できる。大会進行中の切替タイミングは別途決定する |

### 運営確認用店舗の例外

| 店舗と利用条件 | 期待する利用可否 |
| --- | --- |
| 明示指定した運営確認用店舗・プロ未加入・各専用テーマの対象店舗指定なし | 全テーマを利用できる |
| 明示指定した運営確認用店舗・プロ利用期間中・各専用テーマの対象店舗指定なし | 全テーマを利用できる |
| 同じ運営者が所有・作成する別店舗・例外指定なし・プロ利用期間中 | 通常条件を適用し、対象店舗として指定されていない専用テーマは利用できない |
| 同じ運営者が所有・作成する別店舗・例外指定なし・プロ利用期間外 | 通常条件を適用し、専用テーマは利用できず、無料の標準テーマでクロックを利用できる |

## 未決定事項

- 大会進行中にプロ利用期間が終了した場合のテーマ切替タイミング。
- プロへの再加入時の専用テーマの扱い。
- リニューアル時の旧テーマの継続提供・削除・切替方法。
- 専用テーマの制作料金。
- 一店舗に紐づけられる専用テーマ数の具体的な上限。無制限と決定したものではない。
- 専用テーマを店舗に付与する操作。
- 専用テーマ、店舗、プロ利用期間などを表現するデータモデル。
- 運営確認用店舗の例外を付与・解除する操作、権限管理、データモデル。
- 全テーマの動作確認に未公開・廃止テーマまで含めるかどうか。

管理者アカウント自体の仕様は未決定。運営者アカウント単位で全店舗に例外を広げる案の不採用は、管理者アカウント全般の設計を決定するものではない。
