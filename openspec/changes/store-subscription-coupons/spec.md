## 変更の目的と範囲

店舗ごとにプロ契約と特別料金を扱い、協力店・パートナー店へクーポンを提供するための変更仕様を記録する。今回のパートナー向けは無期限とするが、一般のクーポン機能では期間限定も扱う。課金・アプリ機能の実装、具体的な料金の決定、決済事業者やデータモデルの選定は今回の対象外。

## 確定した要件

### 契約と適用の単位

- 当面は一店舗につき一契約とする。店長・オーナーなど個人のアカウントで利用する想定だが、プロ契約・課金・クーポンは店舗単位で扱う。
- 同じ人が複数店舗を管理する場合、一方のみプロ、他方はフリーにできる。ある店舗のクーポンを他店舗へ自動的に適用しない。
- 詳細なアカウントと店舗の関係・権限設計は未決定。

### 割引方式

クーポンごとに、次の三方式から選べる予定仕様とする。

- 指定月額: 適用後の月額を指定する。
- 割合引き: 割引率を指定する。
- 定額割引: 値引き額を指定する。

今回のパートナー向けには指定月額を希望している。各方式の具体的な金額・率や計算の詳細は未決定。

### 特別料金と期間

- 期間限定（例: 3か月）と無期限の双方を扱う。今回のパートナー向け特別料金は無期限とする。
- 期間限定の終了後は通常料金へ戻る。無期限とは期間による終了がないことを指し、後述の交換や実際の契約終了による失効は適用される。

### コードの配布と使用回数

- 複数店舗が利用できる共通コードと、名刺のようなカード一枚ずつに固有コードを載せる一回限りの個別コードの双方を扱う。
- 個別コードの対象店舗は事前に指定しない。最初に適用した一店舗だけが利用できる。
- コードの使用回数と割引の継続期間は別に扱う。一回限りの個別コードでも、無期限の特別料金を付与できる。

### 新規・既存契約への適用

- 新規プロ加入と既存プロ契約の双方を対象とする。新規加入時の適用期間の起算などは未決定。
- 既存プロ契約には次回更新から適用し、支払い済み期間は変更しない。
- 既存プロ契約への3か月限定クーポンは、次回更新から3回の月額請求に適用し、その後は通常料金へ戻す。

### クーポンの交換

- 一店舗で同時に適用するクーポンは一枚とし、重ねて適用しない。
- 新コードの入力だけでは自動上書きしない。現在と変更後の月額・適用期間を提示し、了承後に次回更新で交換する。
- 現在のクーポンを事前に手動解除する必要はない。更新までは従来の割引を維持する。
- 無期限割引を失う交換では、その点も確認時に明示する。

### 契約終了と失効

- クーポンを無効化するのは解約申込時ではなく、実際の契約終了時とする。
- 終了前に解約を取り消し、契約が続く場合は割引を維持する。ただし、期間限定クーポンの期間を延長するものではない。
- 実際に契約が終了したら適用クーポンは失効し、再加入時に復活しない。一回限りの個別コードは使用済みのままとし、再利用させない。

## 受け入れ条件

以下は将来の実装時に確認する条件であり、検証済みではない。

| 条件・操作 | 期待する結果 |
| --- | --- |
| クーポンの割引方式を設定 | クーポンごとに指定月額・割合引き・定額割引の三方式から選べる。計算の詳細は別途決定した仕様に従う |
| 同じ人が店舗A・Bを管理し、Aだけプロ加入 | Bはフリーを維持し、AのクーポンもBへ波及しない |
| 共通コードを複数店舗が利用 | 複数店舗へ適用できる。同一店舗での再適用制限は別途決定する |
| 対象店舗未指定の個別コードを一店舗へ初めて適用 | その店舗だけが利用でき、別店舗は同じコードを使えない |
| 無期限料金を設定した個別コードを一度適用 | コードが一回限りであっても、料金の適用は一回の請求で終わらない |
| 新規プロ加入時にクーポンを利用 | 適用対象として扱う。起算などは決定した仕様に従う |
| 既存プロ契約に3か月限定クーポンを適用 | 支払い済み期間は変更せず、次回更新から3回の月額請求にクーポンの特別料金を適用し、その後通常料金へ戻る |
| 割引適用中に新コードを入力しただけ | 現在のクーポンは上書きされない |
| 月額・期間の比較を確認して交換を了承 | 手動解除なしで次回更新に交換し、更新までは従来の割引を維持する。同時適用は一枚 |
| 無期限割引を失う交換を確認 | 無期限割引を失う旨が明示される |
| 解約を申し込んだが契約はまだ終了していない | 解約申込を理由に割引を無効化しない |
| 実際の終了前に解約を取り消して契約を継続 | クーポン本来の適用期間に従って割引を維持する |
| 実際に契約が終了し、その後再加入 | 以前の適用クーポンは復活せず、使用済みの個別コードも再利用できない |

## 未決定事項と採用していない構想

- 通常月額と、各方式の具体的な指定月額・割引率・値引き額。
- 端数処理、税を含む計算方法、値引きでゼロ未満になる場合の扱い。
- アカウントと店舗の詳細な関係、操作権限、管理権限の引き継ぎ。
- コードの使用開始期限を適用期間と別に設ける案の採否と、具体的な期限。
- 共通コードの同一店舗での再適用制限（契約終了後も含む）。以前の適用が復活しないことと、新たなコード適用の可否は区別する。
- 交換前クーポンの復元可否、予約中の個別コードの消費タイミング、交換予約の変更・取消。
- 決済失敗時の契約・クーポン・適用回数の扱い。
- 税の扱い、請求・決済事業者、新規加入時の適用期間の起算などの請求詳細。
- コードの発行・管理操作、契約・コード・適用期間・交換予約を表すデータモデル。

複数店舗の支払い集約や複数店舗優待は、将来の可能性として説明しただけで採用・実装は決まっていない。これらを今回の要件とは扱わない。
